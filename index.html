StudyTrail / Get started

Set up on your device

A study coach in your terminal. Works on Windows, macOS and Linux. Start with the free offline quiz, then connect an AI provider when you are ready.

  1. Install Python and uv

    Use Python 3.10–3.14 (3.12 recommended). Install uv to keep StudyTrail in its own environment. Open a new PowerShell window on Windows, or Terminal on macOS/Linux, after installation.

    Get PythonInstall uv

  2. Install StudyTrail

    Run these commands in your terminal. They work on all three operating systems.

    uv tool install studytrails
uv tool update-shell

    Close and reopen your terminal so it can find the new command.

  3. Try the offline demo

    No API key needed. Answer a short Python quiz and see your score. Demo progress is saved separately.

    studytrails demo

  4. Start learning with your own notes

    studytrails

    Choose Configure AI to connect OpenAI, Groq, DeepSeek or a compatible provider. Enter your provider's API key and a model that supports tool calling in the app. Live AI usage follows your provider's pricing.

    Choose Manage notes to add a .txt or .md file and a subject. Then choose Start learning with that subject to ask questions and generate quizzes. Use View progress to see your saved results.

Command not found?

Open a new terminal after running uv tool update-shell. If the command is still missing, follow the PATH instructions printed by uv.
